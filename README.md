# SMRITI 🌿
### When Memory Fades, Care Remains.

SMRITI is a healthcare assistance prototype designed to explore how technology can support caregivers and individuals experiencing memory difficulties, including those affected by Alzheimer's disease.

The project brings together medication management, visitor awareness, and safety monitoring concepts in a single interface, with the goal of making everyday care more organized and reassuring.

> **Our vision:** Technology should support care, preserve dignity, and help caregivers provide timely assistance.

---

## 🎯 Problem Statement

Memory-related conditions can make everyday routines more challenging. Caregivers may need to manage medication schedules, maintain awareness of visitor activity, and respond to potential safety concerns.

SMRITI explores how a unified digital platform could help caregivers organize these responsibilities and make care-related information easier to access.

## 💡 Our Solution

SMRITI provides a single interface for medication tracking, visitor activity records, and configurable safety-monitoring demonstrations.

The prototype focuses on usability, caregiver awareness, and transparent communication about which features are currently implemented and which require further development.

## ✨ Features

### 💊 1. Medication Management
- Add medicines with names and dosage information.
- Schedule between one and four doses per day.
- Record the status of individual doses.
- View medication schedules and dose summaries.
- Store medication data in browser storage.

### 👥 2. Biometric Log
- Interface for controlling recognition preferences.
- Visitor activity history interface.
- Visitor notification and unknown-visitor alert settings.
- Demonstration visitor records.

**Current limitation:** Live facial recognition, camera integration, and remote notifications are not connected.

### 🛡️ 3. Safety Monitoring
- Configurable inactivity-monitoring preferences.
- Unknown-visitor monitoring settings.
- Camera and sensor connection status.
- Simulated safety-alert workflow.

**Current limitation:** The prototype does not currently access physical activity sensors or perform real-world monitoring.

### 🧠 4. About SMRITI
- Introduction to the project's purpose and motivation.
- Educational information about Alzheimer's disease.
- An illustration highlighting memory-related brain structures.
- Explanation of how the project aims to support caregivers.
- Transparent classification of implemented, demonstration, and planned features.

### 📊 5. Dashboard
- Medication schedule summary.
- Visitor activity summary.
- Recognition-status indicator.

---

## 🧰 Technology Stack

- **HTML5** — Application structure and content.
- **CSS3** — Styling, layouts, responsive design, and visual components.
- **JavaScript** — Interactive features and application logic.
- **Browser Local Storage** — Local persistence of medication data.

The current prototype is designed to run in a web browser without requiring a backend server.
